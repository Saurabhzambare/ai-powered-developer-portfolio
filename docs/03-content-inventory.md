# 17. Public Content Approval Categories

Every item considered for portfolio/RAG should be treated as one of:

## APPROVED PUBLIC
Safe to publish and ingest.

## PUBLIC AFTER EDIT
Real content requiring cleanup.

## PRIVATE SUPPORTING EVIDENCE
Useful for verification but not publication.

## SUPERSEDED
Old content that must not override newer approved facts.

## PROHIBITED
Sensitive/private material not suitable for public use or AI ingestion.

---

# 18. Privacy / RAG Hard Exclusions

Do not publish or ingest by default:

- Pay stubs
- Tax / T4 records
- Immigration / work-permit documents
- Private academic transcripts/scans
- Private university correspondence
- Raw employment verification letters unless a deliberately redacted public excerpt is approved
- Credential / private reference numbers
- Personal phone number unless intentionally public
- Keys / secrets
- Raw application logs
- Private contact data

RAG sources must pass explicit public-content approval.

---

# 19. Source Priority

When content conflicts, prefer:

1. Verified current official / personal records
2. Explicit current factual corrections
3. Approved current resume
4. Approved project repository/docs
5. Approved current LinkedIn
6. Current project documentation
7. Historical drafts

Never allow historical AI-generated text to override newer verified corrections.
